자주 묻는 질문

키는 어떻게 받아요?

구매 신청에 이메일 주소를 남겨 주세요. 확인 후 그 이메일 전용 48자 키를 보내 드려요. 앱을 처음 열면 뜨는 입력 창에 이메일과 키를 함께 넣으면 되고, 한 번 넣으면 다시 묻지 않아요.

무료로 쓸 수는 없나요?

1점대 버전은 키 없이 무료예요. 내려받기 목록에서 1점대를 받으세요.

말풍선이 알림 배너보다 조금 늦게 떠요

macOS가 알림을 저장하는 데 몇 초 걸려서 배너보다 약 5초 늦게 떠요. 정상이에요.

시스템 배너랑 말풍선이 둘 다 떠요

배너는 macOS가 띄우는 거라 NotiPet이 끌 수 없어요. 펫 말풍선만 보고 싶다면 시스템 설정 › 알림에서 앱별 알림 스타일을 없음으로 바꾸고, 알림 센터에 표시는 켜 두세요.

어떤 앱의 알림만 안 와요

시스템 설정 › 알림에서 그 앱 알림이 켜져 있는지, 메뉴 › 무시하는 앱에 들어 있지 않은지 확인해요. 앱 창 안에서만 뜨는 자체 팝업은 macOS 알림이 아니라서 받을 수 없어요.

권한을 켰는데도 "권한이 필요해요"라고 해요

전체 디스크 접근 권한 목록에서 NotiPet을 − 로 뺀 뒤 + 로 다시 추가하고, NotiPet을 껐다 켜 주세요. 업데이트한 뒤에도 이렇게 한 번 해 주면 돼요.

업데이트 · 삭제는 어떻게 해요?

업데이트: 새 DMG로 응용 프로그램 폴더의 NotiPet을 덮어써요. 1점대에서 2.0 이상으로 올리면 키를 한 번 넣어야 해요. 삭제: 메뉴 › 종료 → NotiPet을 휴지통으로 → 전체 디스크 접근 권한 목록에서 − 로 빼기. 설정까지 지우려면 터미널에서 defaults delete kr.sanghak.notipet
